## 📖 About

**A36 to Flagship** is a KernelSU module that ports Galaxy S25 (S931B) features to the Galaxy A36 — hence the name.

All files were extracted from the S25's `S931BXXUCDZIF` firmware.

> [!CAUTION]
> **INSTALL THIS MODULE AT YOUR OWN RISK.**
>
> I am not responsible if your device gets bricked. The decision to install this module is entirely yours.

## 📦 Installation

### Prerequisites

- A device rooted with **KernelSU**.
- The [Magic Mount Metamodule](https://github.com/Tools-cx-app/meta-magic_mount-rs/releases/tag/v4.0.12) — **required**.

### Fresh installation

1. Download the latest module from the [Releases](https://github.com/devhioliveira/a36_to_flagship/releases) page.
2. Install it through KernelSU.
3. Perform a soft reboot.

> [!IMPORTANT]
> **Coming from One UI 8.5 with the old version installed?**
>
> You **must** remove the old version first — it is **not supported on One UI 9**.
> Remove the old metamodule as well, and use the new Magic Mount Metamodule linked in the [prerequisites](#prerequisites).

## 🔄 Updating

Updating from **V3** onwards:

1. [Uninstall the current version](#-uninstallation) using the **Action** button.
2. Perform a soft reboot.
3. Install the new version from the [Releases](https://github.com/devhioliveira/a36_to_flagship/releases) page.

## 🗑️ Uninstallation

To remove the module correctly and safely, use the module's built-in **Action** button instead of just disabling or deleting it:

1. Open **KernelSU** and go to the **Modules** tab.
2. Find **A36-to-Flagship** and tap the **Action** button.
3. When prompted, press the **Volume Down** button to start the uninstallation.
4. Wait for the process to finish, then perform a **soft reboot**.

> [!WARNING]
> Always uninstall through the **Action** button. Removing the module any other way may leave files behind and cause issues on your device.
